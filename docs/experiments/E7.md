# E7 — Deterministic Replay Harness

**Status: PASSED — take + preset + seed reproduces the render
*bit-identically* across process restarts (stronger than the SSIM ≥0.995
threshold; SSIM ≡ 1.0, zero diff pixels). Transport determinism holds
with a measured convergence bound, and produced one binding design rule
for the phase-5 particle pool.**

Run 2026-07-29, riding the E4 spike (`spikes/e4-render-budget/`, `e7`
mode). Fixed preset (217k points fp4, 500k particles fp2, bloom), camera
and simulation time derived from the take frame index, step-driven replay
(one render per take frame), full-resolution RGBA8 readback hashed per
frame (FNV-1a over all 8.3 MB). GPU/driver state: T550, 610.43.03 (the
tolerance is pinned to this driver per the experiment spec — on this
hardware the tolerance needed is zero).

## Results

- **Run-to-run, across process restarts:** 3 runs on the golden take and
  2 runs on the real 20 s take (603 frames): per-frame hashes identical
  in every case. GPU float nondeterminism on this stack: none observed at
  8-bit output.
- **Contract-level determinism** (RgbdFrame fields, depth planes, JPEG
  bytes, pairing decisions) was separately proven by the phase-2 test
  suite; this experiment adds the pixel level.
- **Transport suite:**
  - pause/step: the E7 mode *is* step-driven — covered by construction.
  - paced vs free-run (speed changes): content is frame-indexed, pacing
    only affects wall time; verified at contract level in phase-2 tests.
  - loop wrap: contract-level verified (no fabricated gaps) in phase-2.
  - **seek-to-N vs play-to-N: converges and stays bit-identical after
    K = 147 frames (≈4.9 s)** — exactly the max particle lifecycle
    period, measured 356/356 identical frames after convergence.

## The finding that matters (phase-5 design rule)

The first spike version tied particle respawn to *accumulated age*; after
a seek, respawn schedules were permanently phase-shifted and **seek runs
never converged** (K = ∞). Fix: **lifecycle boundaries anchored to the
absolute frame index** (`(frame + slot) % period(slot) == 0`), making
particle state a pure function of (slot, frame-history window) — after
one full cycle, any transport discontinuity converges. The phase-5 pool
inherits this as a requirement, alongside discovery 02 §5's slot
determinism: **no particle state may depend on when the transport last
jumped; warm-up bound = max lifecycle period, documented per preset.**

## Consequences

- Deterministic replay is confirmed as the visual regression harness:
  golden take + preset + per-frame hash list = the fixture. Image-diff
  (SSIM) machinery is unnecessary on this driver/GPU until a hash ever
  mismatches — keep hashes as the primary check, fall back to SSIM
  tolerance only if a driver update breaks exactness (re-measure then).
- Seek warm-up: transport UI (phase 10) should either fast-forward
  silently for the warm-up window when frame-exact particle state
  matters, or accept visible convergence — per-look choice.
